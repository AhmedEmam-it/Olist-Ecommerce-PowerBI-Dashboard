# 🇧🇷 Brazil E-Commerce Sales Analysis — Power BI

## 📊 Project Overview

This project analyzes Brazilian e-commerce data to identify sales performance, customer behavior, product performance, and delivery trends using Microsoft Power BI.

## 🎯 Objectives

* Analyze total sales and orders
* Identify top-performing products
* Analyze customer distribution
* Measure delivery performance
* Identify sales trends over time
* Build an interactive business dashboard

## 🛠️ Tools Used

* Power BI
* Power Query
* DAX
* Excel / CSV
* Data Cleaning
* Data Visualization
